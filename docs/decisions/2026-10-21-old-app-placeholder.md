# The old app is a placeholder

Mark's 21 Oct review (working agreement task 3.11) asked to remove the till's
exception for paying a workshop job without a sign-off, which
`2026-10-16-mechanic-sign-off.md` kept for the old app ("The old app keeps
finishing jobs without a sign-off until its screen is replaced; it is not
changed").

## Answers

1. **The old app never takes payment for a workshop job.** Jack, 21 Oct: "I
   think I might not have explained it completely beforehand, but the old app
   should never take payment for a finished workshop job. Nobody uses the old
   till. I think we just need to consider the old till to be a placeholder
   currently until we can completely delete it. I think anything old
   app-related should just be a placeholder. Maybe for now we can send it to
   new till, but ultimately, I want to get rid of the old app completely."

   This changes the 16 Oct line about the old app: a workshop job's payment
   in the old app (its till's Complete sale on a job's order, and an order's
   Convert to sale) goes to the new till, where the sign-off is asked, and the
   server refuses a job's payment that doesn't answer the sign-off question.

2. **Everything in the old app is a placeholder**, to be deleted completely.
   Work on it is only what keeps it from doing harm until then; nothing new is
   built there.
