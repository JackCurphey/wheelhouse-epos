# Decided while building: November 2026, Jack

### 11 Nov 2026: Quick buttons on the server (`openspec/changes/owner-setup-till-payments-eod` group 1, `set-till-quick`, `set-till-quick-add`)

Decided here, for Jack to overrule.

1. **A button whose item is off sale stays, marked "Not on sale".** The
   server sends `onSale: false` for it; the till will hide it and the Settings
   row will say "Not on sale". Checked: `setup.mjs` draws no off-sale button,
   and design.md section 5 point 4 says "'Not on sale' on its Settings row,
   hidden on the till". No built screen marks an off-sale item this way (the
   services list hides inactive services), so this is new.
2. **Name limits: a group up to 20 characters, a button's label up to 40.**
   An empty label shows the item's own name. Checked: no limit is drawn, and
   design.md section 5 point 5 sets them. Chosen to fit: a group is a pill,
   and a button is a tile. *Pattern:* the nearest built limit is a booking
   slot's name, 40 characters (`server/routes/workshop-settings.js`).
3. **A button stays when its product or service is deleted, marked "Not on
   sale".** Deleting either in the app only turns it off, so the button
   follows point 1. Only if the row itself is removed (today, when a whole
   shop is removed) do its buttons go with it. Not drawn, and no decision
   covers it. *Pattern:* a product's price history (migration 122) and a
   service's included services (migration 031) go with a removed row the
   same way.
