# Decided while building: November 2026, Jack

### 11 Nov 2026: Other ways to pay (owner-setup-till-payments-eod, set-pay-other, set-pay-ways)

Decided here, for Jack to overrule.

1. **Remove is the drawn ✕ button, not a word.** The spec says each row has "an outlined Remove"; the drawing (`setup.mjs` otherRow) draws a borderless 44px button with `icon('close', 16)` and `aria-label="Remove ${t}"`. Built as drawn: a ✕ named "Remove Finance" and so on.
   *Pattern:* Storage slots' Remove on each slot (`storage-slots-settings.tsx`), the same ✕ in a 44px button.
2. **The summary names the ways as they are written.** The drawn summary is "Finance, Cycle to Work, payment link" (`settings-frame.mjs` payFolds; the spec's scenario repeats it), with "payment link" in small letters. No rule makes those words from the list (Cycle to Work keeps its capitals), so the summary is the names joined with commas: "Finance, Cycle to Work, Payment link", or "None".
   *Pattern:* Customer groups' summary, the groups' names joined with ", " (`customer-groups-settings.tsx` useCustomerGroupsSummary).
3. **Saved and Undo show in the fold.** The drawing's "Saved · Undo" is a dark note at the foot of the page (`settings-frame.mjs` toastHtml); that shared note isn't built on main yet. Until it is, Add and Remove show "Saved." with an Undo button on a status line under the fold's note, and an error replaces it.
   *Pattern:* the "Saved." status line in Ways to pay (`ways-to-pay-settings.tsx`), and the ghost Undo button in Categories (`categories-settings.tsx`, "Undo removing").
4. **Undo puts a removed way back where it was, with its line.** Design 4 says "A shop's own rows have no line." The Add box sends only a name, so a way the shop types has none; the line is sent only by Undo, to put back a drawn row as it was. A line is up to 120 characters (not drawn; the longest drawn line is 55).
   *Pattern:* quick buttons' Undo, a POST with the position it came from (`server/routes/quick-buttons.js` on `claude/quick-buttons-server`).
5. **A name already on the list says so.** Not drawn. The server refuses it with "That way to pay is already on the list", and the fold shows those words, keeping what was typed. A name over 30 characters can't be typed (the box stops at 30).
   *Pattern:* the server's own words shown in the fold, as Ways to pay shows them (`ways-to-pay-settings.tsx` words()); the quick buttons' "There’s already a group with that name".
