# Badge

A small pill showing the state of a job, booking or order. Uses the shared status colours only — never decorative.

| State | Tokens |
| --- | --- |
| Awaiting confirmation | `status-pending-bg` / `status-pending-ink` |
| Booked in | `status-scheduled-bg` / `status-scheduled-ink` |
| Waiting for parts | `status-waiting-bg` / `status-waiting-ink` |
| On hold, offline | `status-hold-bg` / `status-hold-ink` |
| Ready, paid | `status-complete-bg` / `status-complete-ink` |

12px, weight 600, `radius-pill`. The words always say the state; colour only supports them.
