# Field

A label above an input, with an optional hint or error below.

- Label: `label` style, `foreground`. Always a real `<label>` tied to the input.
- Input: 44px tall, `card` fill, `input` border (3:1 against the card), `radius-md`; focus shows a 2px `primary` ring.
- Hint: `small`, `muted-foreground`. Error: `small`, `destructive`, and the input border turns `destructive`.
