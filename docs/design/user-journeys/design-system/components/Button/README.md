# Button

Buttons start an action; the label says exactly what happens.

- **primary** (filled `primary`, `primary-foreground` text): the one main action on a screen — Take payment, Book in, Save.
- **outline** (`card` fill, `input` border): secondary actions next to a primary one.
- **ghost**: low-emphasis actions such as Cancel.
- **destructive** (filled `destructive`): void, delete. Ask for confirmation first.

44px tall minimum, `radius-md`, label weight 600, 15px. Full width at the bottom of phone screens. Built from the Wheelhouse registry button (`registry/primitives/button.tsx`).
